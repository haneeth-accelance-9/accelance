Governance

The approval model isn't a feature. It's the product.

Every autonomous action across every Accelance engagement inherits the same three-tier system — it is not optional styling, and it is not configurable away.

Three tiers. One rule: nothing acts silently.

Autonomous actions still log to an audit trail. Review-required actions wait for a named approver. Mandatory-approval actions cannot execute without one. There is no fourth tier that skips this.

Every action, timestamped and attributable

Approvals, rejections, and autonomous completions all write to the same audit log — visible to compliance stakeholders, not just engineering.
