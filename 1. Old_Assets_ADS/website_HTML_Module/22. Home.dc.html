How it works

Every agent action starts as a proposal, not a decision

Green means the agent acts on its own. Amber means a person reviews first. Red means it never moves without explicit sign-off. The color changes — the rule never does.

Autonomous — low-risk actions the agent completes, always logged.
Review required — the agent proposes; a person approves first.
Mandatory approval — high-impact actions never move without sign-off.
